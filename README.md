# 🗂️ בונה שערי נספחים - אליהו ביטון

מערכת חכמה לזיהוי אוטומטי של נספחים מכתבי טענות ויצירת שערי נספחים וטבלאות.

## 🎯 מה המערכת עושה?

המערכת מקבלת קובץ Word (כתב טענות לבית משפט), מזהה אוטומטית את כל הנספחים שמוזכרים בו, ויוצרת שני מסמכים:

1. **טבלת נספחים** - טבלה מסודרת עם מספרי הנספחים ושמותיהם
2. **שערי נספחים** - מסמך עם עמוד נפרד לכל נספח (מוכן להדפסה והדבקה על הנספחים)

## ✨ תכונות

- ✅ זיהוי אוטומטי של נספחים מקובץ Word
- ✅ תמיכה בפורמטים שונים:
  - "נספח 1 - שם הנספח"
  - "נספח מספר 2 - שם הנספח"
  - "נספח מס' 3 - שם הנספח"
- ✅ יצירת טבלה מעוצבת ומסודרת
- ✅ יצירת שערי נספחים מעוצבים (במרכז, 5 שורות מלמעלה)
- ✅ הורדת שני הקבצים כקובץ ZIP אחד

## 🚀 התקנה

1. התקן את הספריות הנדרשות:
```bash
pip install -r requirements.txt
```

2. הרץ את השרת:
```bash
python main.py
```

3. פתח את הדפדפן בכתובת:
```
http://localhost:5000
```

## 📖 איך משתמשים?

1. **הכן קובץ Word** עם כתב הטענות שלך
2. **העלה את הקובץ** דרך הממשק
3. **קבל קובץ ZIP** עם שני המסמכים:
   - `טבלת_נספחים.docx` - הטבלה המסודרת
   - `שערי_נספחים.docx` - השערים להדפסה

## 📝 דוגמה

אם בכתב הטענות כתוב:
```
אני מצרף נספח 1 - חוזה העסקה מיום 15.3.2023
בנוסף, נספח 2 - תדפיס חשבון בנק
כמו כן, נספח מספר 3 - תכתובת אימיילים
```

המערכת תזהה 3 נספחים ותיצור:
- טבלה עם 3 שורות
- 3 עמודים עם שערי נספחים
